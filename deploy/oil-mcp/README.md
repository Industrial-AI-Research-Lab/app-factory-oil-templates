# Oil MCP container stack

This directory owns the canonical container definitions for Docling, Domain
Research, Reporting, and read-only FalkorDB MCP. Hiddify Core provides isolated
outbound access for Domain Research. The FalkorDB database itself is external
to this Compose project.

`docker-compose.yml` is the only Compose definition for this deployment and
contains every runtime service.

Domain Research has no direct Internet route: it joins only the internal
`mcp_private` network and sends outbound requests through Hiddify Core. The
proxy accepts the SSH, Mieru, Hysteria2, and VLESS links supplied by Hiddify
Manager. It has no direct fallback outbound, so application traffic is
fail-closed when every proxy node is unavailable. The proxy container accesses
the HTTP or HTTPS subscription URL directly only to bootstrap and refresh its
node list. A failed refresh keeps the last working configuration; an initial
failure keeps the service unhealthy. The one exception is object storage: the
renderer passes `OIL_MCP_OBJECT_STORAGE_ALLOWED_ORIGINS` to the proxy in
`hiddify-proxy.env`, and the proxy sends those hosts through its direct
outbound, so signed uploads and downloads do not depend on the VPN nodes.

## Minimal environment

For Docling only, the Compose interpolation contract needs these values:

| Variable | Required value |
| --- | --- |
| `OIL_MCP_SOURCE` | Absolute path to this repository checkout. |
| `OIL_MCP_RUNTIME_ENV_DIR` | Absolute path to a private directory generated by `render-runtime-env.sh`; the `docling` target creates the expected empty service env files. |

For the full stack, export these additional secrets and connection settings
before rendering the runtime directory:

| Variable | Used by |
| --- | --- |
| `HIDDIFY_SUBSCRIPTION_URL` | Hiddify Manager subscription; secret HTTP or HTTPS URL. |
| `OIL_MCP_TAVILY_API_KEY` | Domain Research; secret. |
| `OIL_MCP_BUNDLE_RECEIPT_KEY` | Domain Research; secret of at least 32 bytes. |
| `OIL_MCP_OBJECT_STORAGE_ALLOWED_ORIGINS` | Domain Research and Reporting; comma-separated HTTP or HTTPS origins. |
| `OIL_MCP_FALKORDB_HOST` | FalkorDB database hostname or IP, without scheme or path. |
| `OIL_MCP_FALKORDB_PASSWORD` | FalkorDB database password; secret. |

Use the universal user subscription URL for `HIDDIFY_SUBSCRIPTION_URL`, not a
format-specific `/clash` or `/clashmeta` link. Those formats cannot represent
every SSH and Mieru field that Hiddify Core needs.

The existing external Docker network named `AppFactory-lab_internal` must be
reachable by Reporting and FalkorDB MCP. Domain Research uses its own internal
network plus Hiddify Core and does not join that shared network.

## Full environment reference

### Compose interpolation

| Variable | Default | Purpose |
| --- | --- | --- |
| `OIL_MCP_SOURCE` | required | Repository checkout used as every MCP build context. |
| `OIL_MCP_RUNTIME_ENV_DIR` | required | Private directory containing the rendered service env files. |
| `OIL_MCP_BIND_ADDRESS` | `127.0.0.1` | Host bind address for Domain Research. |
| `OIL_MCP_DOCLING_PORT` | `8002` | Docling Adapter host port. |
| `OIL_MCP_DOMAIN_RESEARCH_PORT` | `8023` | Domain Research host port. |
| `OIL_MCP_REPORTING_PORT` | `8024` | Reporting host port. |
| `OIL_MCP_FALKORDB_PORT` | `8025` | FalkorDB MCP host port. |
| `OIL_MCP_HIDDIFY_REFRESH_SECONDS` | `3600` | Positive interval between subscription refresh attempts. |
| `OIL_MCP_HIDDIFY_VOLUME_NAME` | `oil-mcp_hiddify_state` | Named volume containing the subscription URL and last working Hiddify configuration. |

### Runtime renderer

| Variable | Default | Purpose |
| --- | --- | --- |
| `HIDDIFY_SUBSCRIPTION_URL` | required for Domain Research | Secret provider URL written to a mode-`0600` runtime file and copied into Hiddify's private state volume before startup. |
| `OIL_MCP_TAVILY_API_KEY` | required for Domain Research | Tavily credential. |
| `OIL_MCP_BUNDLE_RECEIPT_KEY` | required for Domain Research | Stable receipt-signing secret, at least 32 bytes. |
| `OIL_MCP_OBJECT_STORAGE_ALLOWED_ORIGINS` | required for Domain Research and Reporting | Allowed HTTP or HTTPS presigned-URL origins. |
| `OIL_MCP_MAX_DOWNLOAD_BYTES` | unset (service default 52428800) | Domain Research download limit per artifact; written as `MAX_DOWNLOAD_BYTES` only when set. |
| `OIL_MCP_MAX_QUERY_ROWS` | unset (service default 200) | Domain Research `query_collection` row cap; written as `MAX_QUERY_ROWS` only when set. |
| `OIL_MCP_SQLITE_OPERATION_BUDGET` | unset (service default 100000) | Domain Research SQLite VM step budget; written as `SQLITE_OPERATION_BUDGET` only when set. |
| `OIL_MCP_REPORT_GRAPH_MAX_NODES` | `500` | Maximum graph nodes in a report. |
| `OIL_MCP_REPORT_GRAPH_MAX_EDGES` | `2000` | Maximum graph edges in a report. |
| `OIL_MCP_FALKORDB_HOST` | required for FalkorDB MCP | Redis-protocol database host. |
| `OIL_MCP_FALKORDB_DATABASE_PORT` | `6379` | Redis-protocol database port; port `13000` is rejected because it is the Browser HTTP port. |
| `OIL_MCP_FALKORDB_USERNAME` | `default` | FalkorDB database username. |
| `OIL_MCP_FALKORDB_PASSWORD` | required for FalkorDB MCP | Database password. |

The renderer writes `TAVILY_API_KEY`, `BUNDLE_RECEIPT_KEY`,
`OBJECT_STORAGE_ALLOWED_ORIGINS`, `REPORTING_UPLOAD_ALLOWED_ORIGINS`,
`REPORT_GRAPH_MAX_NODES`, `REPORT_GRAPH_MAX_EDGES`, `FALKORDB_HOST`,
`FALKORDB_PORT`, `FALKORDB_USERNAME`, and `FALKORDB_PASSWORD` to separate
service files. Reporting and FalkorDB never receive the Tavily or receipt
secrets. `ALLOW_INSECURE_OBJECT_STORAGE` is fixed to `true` in this deployment,
so explicitly listed HTTP origins are accepted. The exact-origin allowlist
remains mandatory; prefer HTTPS whenever traffic crosses an untrusted network.

Domain Research's `CALCULATOR_SCAN_BUDGET` (default `1000000`, see
`mcp/domain-research/README.md`) has no `OIL_MCP_*` passthrough here, the same
as `MAX_SEARCH_RESPONSE_BYTES`, `SQLITE_MAX_VALUE_BYTES` and
`REQUEST_TIMEOUT_SECONDS`: it is optional and only worth setting to raise the
skip-reason scan's own budget, so an operator who needs a non-default value
adds `CALCULATOR_SCAN_BUDGET=…` directly to the rendered
`domain-research.env` rather than through `render-runtime-env.sh`.

## Validate the configuration

Render disposable runtime files and validate interpolation without starting
containers:

```bash
runtime_env_dir="$(mktemp -d)"
export OIL_MCP_SOURCE="$PWD"
export OIL_MCP_RUNTIME_ENV_DIR="$runtime_env_dir"
export OIL_MCP_TAVILY_API_KEY=test-key
export OIL_MCP_BUNDLE_RECEIPT_KEY=01234567890123456789012345678901
export OIL_MCP_OBJECT_STORAGE_ALLOWED_ORIGINS=https://objects.example.test
export OIL_MCP_FALKORDB_HOST=falkordb.internal
export OIL_MCP_FALKORDB_PASSWORD=test-password
export HIDDIFY_SUBSCRIPTION_URL='https://proxy.example.test/subscription?token=test'
bash deploy/oil-mcp/render-runtime-env.sh "$runtime_env_dir" all
docker compose -f deploy/oil-mcp/docker-compose.yml config --quiet
rm -rf -- "$runtime_env_dir"
```

## Start

Render the runtime files using real values, create Hiddify once so Compose
creates its state volume, copy the subscription into that volume, then start
the stack:

```bash
export OIL_MCP_SOURCE="$PWD"
export OIL_MCP_RUNTIME_ENV_DIR="$(mktemp -d)"
bash deploy/oil-mcp/render-runtime-env.sh "$OIL_MCP_RUNTIME_ENV_DIR" all
docker compose -f deploy/oil-mcp/docker-compose.yml build hiddify-proxy
docker compose -f deploy/oil-mcp/docker-compose.yml create --force-recreate hiddify-proxy
proxy_container="$(docker compose -f deploy/oil-mcp/docker-compose.yml ps -aq hiddify-proxy)"
docker cp "$OIL_MCP_RUNTIME_ENV_DIR/hiddify/subscription-url" \
  "$proxy_container:/var/lib/hiddify/subscription-url"
docker compose -f deploy/oil-mcp/docker-compose.yml up -d --build --force-recreate --remove-orphans --wait --wait-timeout 300
```

Start only one service group from the same Compose file with:

```bash
docker compose -f deploy/oil-mcp/docker-compose.yml up -d --build --remove-orphans docling-mcp docling-adapter-mcp
docker compose -f deploy/oil-mcp/docker-compose.yml up -d --build --remove-orphans domain-research-mcp
docker compose -f deploy/oil-mcp/docker-compose.yml up -d --build --remove-orphans reporting-mcp
```

## Windows Domain Research smoke test

Place `.env` in `mcp/domain-research/server`, then run this command from the
repository root in PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\deploy\oil-mcp\smoke-domain-research.ps1
```

The script builds Domain Research, starts it with Hiddify, checks proxy egress,
stops Hiddify to prove that Domain Research fails closed, restarts it, calls the
`search_web` MCP tool against Tavily, and verifies the provider's successful
response in the service logs. Containers remain running for log inspection in
the isolated `oil-mcp-smoke` Compose project on host port `18023`. Use
`-EnvFile C:\path\to\.env` or `-Query "search text"` to override the defaults.

Direct MCP ports have no authentication in this project. Keep loopback binds
or enforce the required firewall and proxy boundary.

## Status and logs

```bash
docker compose -f deploy/oil-mcp/docker-compose.yml ps
docker compose -f deploy/oil-mcp/docker-compose.yml logs -f domain-research-mcp
```

The published defaults are Docling Adapter `8002`, Domain Research `8023`,
Reporting `8024`, and FalkorDB MCP `8025`. Docling's internal conversion
service and Hiddify's mixed proxy port are not published. Domain Research stays
on the internal network; Hiddify accepts its published port and forwards it to
the service without giving the service a direct internet route.

## Stop

```bash
docker compose -f deploy/oil-mcp/docker-compose.yml down
```

The Hiddify named volume remains available for the next start. Remove it only
when intentionally discarding the subscription and last working proxy
configuration.

## Tests

The Dockerfiles retain dedicated test stages without requiring more Compose
files:

```bash
docker build --target test -f deploy/oil-mcp/domain-research.Dockerfile -t domain-research-test .
docker run --rm -v "$PWD:/workspace:ro" domain-research-test \
  python -m pytest mcp/domain-research/server/tests -q
docker build --target test -f deploy/oil-mcp/reporting.Dockerfile -t reporting-test .
docker run --rm -v "$PWD:/workspace:ro" reporting-test \
  python -m pytest mcp/reporting/server/tests -q
```
