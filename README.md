# app-factory-oil-templates

Компонент прикладной шаблонизации инновационного программного решения на базе МАС БФМ для цифрового инжиниринга в нефтегазовой отрасли (AppFactory).

Репозиторий содержит исходный код, приведённый в документе «Текст программы» RU.СНАБ.01038-02 12 02.
Состав и структура каталогов совпадают с документом; прежнее наименование продукта
заменено на AppFactory, адреса испытательных стендов — условными значениями.

## Назначение

Компонент содержит пакет предметной конфигурации (роли агентов, включая профили профессиональных ролей, процессы, подсказки, разрешения инструментов), службу календарного планирования обустройства месторождений, службу выпуска отчётов по шаблонам и средства развёртывания предметных служб MCP. Назначение и устройство компонента изложены в документе «Описание программы» RU.СНАБ.01038-02 13 02.

## Состав

Раздел содержит полный исходный текст компонента прикладной шаблонизации. В состав входят конфигурации нефтегазовых ролей и процессов, включая профили профессиональных ролей, и сценарные модули из каталога experiments/deep-domain-research, служба календарного планирования обустройства месторождений из каталога mcp/planning, служба выпуска отчётов из каталога mcp/reporting с шаблонами отчётов, файлы развёртывания предметных служб из каталога deploy/oil-mcp и проверка применения предметного пакета конфигурации.

## Происхождение

Код собран из репозитория продукта AppFactory (ветка разработки демонстрационных сценариев
и связанные с ней ветки служб) и предназначен для сопровождения отчётной документации.
Описание устройства и порядка запуска приведено в документах «Описание программы»
и руководствах комплекта.
